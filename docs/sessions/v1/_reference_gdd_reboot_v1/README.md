# Roxana GDD Reboot v1

Paquete inicial de documentación para redefinir los cuatro Mundos Aplicados alrededor de una identidad jugable propia.

## Archivos

- `00_ROXANA_GDD_GLOBAL_REBOOT_v1.md` — biblia global y reglas compartidas.
- `01_OHMDAL_GDD_REBOOT_v1.md` — electrónica / CONECTAR / HD-2D adventure.
- `02_PHYSICA_GDD_REBOOT_v1.md` — física / EXPERIMENTAR / physics puzzle-platformer.
- `03_BITLAND_GDD_v0.1.md` — computación / PROGRAMAR / top-down programmable adventure.
- `04_ARITHMOS_GDD_v0.1.md` — matemática / TRANSFORMAR / isometric puzzle adventure.
- `05_AUDITORIA_CANON_LEGACY.md` — auditoría de material previo y política de migración.

## Importante

Estos documentos son una base de preproducción, no canon automático. Ohmdal y Physica heredan material previo; Bitland y Arithmos son propuestas nuevas. El siguiente paso es convertir cada GDD en una versión de producción con arcos, mapas de contenido, personajes, sistemas, vertical slice y criterios de aceptación aprobados.
