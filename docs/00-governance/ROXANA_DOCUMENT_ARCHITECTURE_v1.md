# Organización de documentación

Una fuente por asunto. [El índice](../README.md) permite encontrarla.

- `10-global`: narrativa y sistemas compartidos.
- `20-worlds`: diseño y contenido de cada mundo.
- `arco1` y `3d`: arte, assets y comprobaciones útiles.
- `80-production`: herramientas que todavía se utilizan.

Actualiza documentos existentes. No se exige frontmatter, jerarquías numeradas,
plantillas de aprobación ni un informe por cada iteración. Conserva procedencia y
licencias junto a los assets. Capturas y resultados generados van en `output/`.
Retira instrucciones caducadas; Git conserva su historia.
