# Uso de recursos

Delega tareas independientes y acotadas cuando reduzca tiempo o contexto.
No repitas una auditoría ya resuelta ni fuerces una jerarquía de proveedores.
Comprueba las cuotas actuales; una promoción histórica no autoriza gasto.

La implementación y su revisión independiente deben ser trabajos distintos.
Si una herramienta no está disponible, usa otra dentro del alcance autorizado.
Evita generar tareas, reportes y rondas de aprobación que no cambien el resultado.
