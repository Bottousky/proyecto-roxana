## Encargo

Diseñá un contrato justo para comparar Ohm como sprite/impostor direccional y como hard-surface
procedural Three.js. Deben conservar identidad, altura aparente, acciones, tiempo de producción y
presupuesto visible equivalentes. Especificá silueta/partes, estados, pivotes o sockets, frente,
contacto con suelo, collider, sombra, materiales compartidos, accesibilidad, draw calls, memoria,
editabilidad y disposal. La variante procedural debe ser modular y determinista, nunca una malla
monolítica; no se permite Meshy ni generación paga.

Incluí dos plantillas de manifest compatibles y un protocolo de decisión por integración espacial,
actuación, editabilidad y coste medido. No afirmes métricas no observadas ni elijas ganador antes de
integrar con la cámara aprobada.
