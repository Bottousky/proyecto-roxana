## Ejecución

Una sola estrategia: **reconciliar las particiones que ya existen**, no proponer un mapa nuevo. Las
zonas, los anclajes, los encuadres y las horas están fijados por código o por canon congelado; este
documento nombra la escena que esos elementos ya delimitan y le pone tiempo.

Lo único que el paquete **agrega** es el reparto de duración, y se declara como objetivo de diseño
falsable en `ARC1-030`, no como medición.

Si la reconciliación produjera una contradicción entre canon congelado y runtime, el paquete se
detiene y la reporta. No se elige el número que cierre.
