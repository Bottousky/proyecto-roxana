## Objetivo

`createOhmdalLab(container)` existe: el laboratorio se construye dentro del elemento que recibe, con
su propia UI, y se puede pausar, reanudar y destruir. Hoy no existe ninguna de esas cuatro cosas.

## Terminado cuando

- `src/labs/ohmdal-hd2d-preprod/lab.ts` exporta `createOhmdalLab(container: HTMLElement)` y el módulo
  **no tiene efectos de nivel superior**: importarlo no crea un `WebGLRenderer`, no registra
  listeners y no lee el documento;
- el handle devuelto expone `pause()`, `resume()`, `dispose()`, `snapshot()` y `advanceTime(ms)`;
- `pause()` detiene el bucle —`resume()` lo reanuda sin salto de `dt`— y `advanceTime()` sigue
  funcionando con el bucle detenido, que es como se mide sin depender de `rAF`;
- `dispose()` deja el contenedor **vacío**, quita todos los listeners que el laboratorio registró en
  `window` y libera geometrías, materiales, texturas y el renderer;
- la UI del laboratorio —panel superior, HUD, tarjeta de diagnóstico, D-pad táctil— la construye
  `labUi.ts` dentro del contenedor; no queda ningún `getElementById` sobre el documento anfitrión;
- `labs/ohmdal-hd2d-preprod/index.html` queda reducido a contenedor más arranque;
- el recorrido determinista produce el **mismo** `render_game_to_text()` que antes del cambio, en los
  mismos puntos de muestreo;
- `npm run build` PASS;
- `npm test` PASS;
- `git diff --check` PASS.

## Ejecución

Una sola estrategia: **mover, no reescribir**. La simulación de `main.ts` se traslada a `lab.ts`
dentro de una función, con la misma aritmética, los mismos umbrales y los mismos textos. Lo que
cambia es dónde vive el estado —de módulo a closure— y quién construye la UI.

Tres cuidados que decide el contrato, no el ejecutor:

1. **Textos.** Los del panel, el HUD y el diagnóstico se copian **textuales** del HTML y del
   `main.ts` actuales. Ninguno se reescribe, se acorta ni se traduce.
2. **Estilos.** El bloque `<style>` de la página pasa a `labUi.ts` como hoja inyectada una vez y
   retirada en `dispose()`. Los selectores no cambian de valores; cambia dónde se declaran.
3. **`dt` al reanudar.** `resume()` reinicia la marca de tiempo previa. Reanudar después de un
   minuto pausado no puede producir un salto de simulación.
