paleta nueva. El harness es la fuente; el documento nombra el patrón que esos números ya forman y lo
vuelve obligatorio hacia adelante.

que entra—, el paquete se detiene y lo reporta como contradicción entre canon y runtime. No se
maquilla el número para que cierre.
