# Paquetes

Contratos de sesión del ticket **activo**. El protocolo está en [`../PACKETS.md`](../PACKETS.md).

Sólo existe carpeta para el ticket activo. No se preparan paquetes de tickets futuros: el contrato
se escribe en `/arc-plan`, justo antes de ejecutarlo.

```text
packets/
  _TEMPLATE.md
  ARC1-NNN/
    ARC1-NNN-A.md
    ARC1-NNN-B.md
```

Ticket activo: `ARC1-004 — READY`. Todavía sin paquetes: los define `/arc-plan ARC1-004`.
