# Region Pack — Manantial / Central Hidroeléctrica

Status: prepared for A1 review. Priority: highest authored environment.

## Concept
An old hydroelectric headworks carved into Ohmdal's pale stone where the spring/lake feed is captured by channels, sluice and a compact turbine-generator system. It should feel like civic infrastructure grown into the city, not a modern concrete dam and not a fantasy water temple.

## Hero landmarks
- intake / sluice gate;
- visible water path;
- turbine-generator assembly;
- return/ground path and protection;
- large ceramic insulators and outgoing busbars;
- measurement platform.

The turbine-generator assembly is an identity candidate: final high-detail production requires a sufficient approved reference pack / hero gate.

## Dormant state
Water held/still, machinery inert, sparse sound, no decorative glow. The causal path must already be inferable.

## Restored state
Flow ramps up, turbine/generator starts, contacts respond, localized electrical events appear only where physically justified, spray/mist follows actual water activity, outgoing conductors read as energized by consequence rather than neon.

## Canonical shots
`manantial-approach`, `hydro-central-wide`, `sluice-gate-interaction`, `generator-platform`, `restored-manantial`.

## Concept-generation prompt seed
"Ohmdal hydroelectric spring headworks, old pale eroded stone civic infrastructure, compact exposed turbine generator, bronze/copper busbars with ceramic insulators, visible sluice and water channel, technical fantasy grounded in real hydroelectric mechanisms, warm dusty afternoon, restrained aged materials, no neon, no magical runes, no modern concrete megadam, readable gameplay circulation, authored 3D environment concept."

## Avoid
Blue glowing water, cyberpunk plant, random pipe jungle, giant dam scale that breaks the validated route, fantasy waterfall shrine.
