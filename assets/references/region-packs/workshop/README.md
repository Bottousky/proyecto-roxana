# Region Pack — Taller de Lumen

Status: prepared for A1 review. Spatial authority: current workshop runtime/interior.

## Concept
A practical diagnostic atelier inherited from a technically stronger past. Warm, tactile and dense enough to feel used, but not a clutter maze. Wood supports, ceramic, glass, aged metals and instrument cases serve function.

## Landmarks
Galvanoscopio bench, Lumen's working area, tool storage, repair evidence, local conductors and readable exits.

## Authored focus
Make the bench and tools feel physically operable; preserve measurement affordances and mobile readability. Let wear/repair tell the story instead of fantasy props.

## Canonical shots
`workshop-exterior`, `workshop-interior-tools`, `galvanoscope-first-person`.

## Avoid
Alchemist laboratory language, potions/runes, random brass ornament, hiding tools behind dressing.
