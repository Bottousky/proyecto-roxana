# Region Pack — Plaza

Status: prepared for A1 review. Spatial authority: current PlayCanvas Plaza + accepted Stage 5 baseline.

## Concept
Civic electrical hub, old but functioning architecture in suspension rather than ruin. Pale stone, ordered exposed conductors, ceramic insulators, aged copper without passive glow. The existing Plaza is already visually accepted: do not redesign it.

## Authored focus
- preserve Portal Ω / Ohm / Taller / Omega hierarchy;
- improve restored-state readability only through functioning services, motion, bell/relay consequence and subtle practical light;
- integrate late-route return without turning the hub into a victory reskin.
