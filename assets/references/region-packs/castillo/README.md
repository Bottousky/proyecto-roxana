# Region Pack — Castillo de la Red

Status: prepared for A1 review.

## Concept
A monumental civic distribution stronghold: castle by scale, permanence and guarded access, substation by function. Architecture organizes and protects the network. The player should understand that one source feeds several services and that branches can be isolated independently.

## Hero landmarks
Central bus / distribution spine, branching galleries, isolators, protections, seals/lockouts, service indicators anchored to real branches, maintenance balcony/panel.

The main distribution landmark is an identity candidate; final hero production requires sufficient approved references.

## Authored focus
Use structure and routing to make parallel/mixed distribution visually legible. Dense component work may use diegetic maintenance close-ups, but all manipulation must affect the same world model.

## Canonical shots
`castle-gate-open`, `castle-distribution-hall`.

## Concept-generation prompt seed
"Monumental civic electrical distribution hall inside an ancient stone castle of Ohmdal, pale masonry, giant orderly copper busbars, ceramic standoff insulators, switchgear and protected branch galleries integrated into architecture, practical maintenance balconies, warm dusty daylight, grounded technical fantasy, readable series/parallel distribution, no throne-room cliché, no neon, no steampunk clutter."

## Avoid
Generic medieval throne room, glowing schematic walls, puzzle board detached from the physical network, ornamental cables with no function.
