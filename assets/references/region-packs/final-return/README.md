# Region Pack — Final Return

Status: prepared for A1 review.

## Concept
The final return is not a new visual language. It is the same world now understood and functioning. The emotional payoff comes from persistent systems visibly and audibly working as the player backtracks.

## Authored focus
- moving/working water where restored;
- service-state changes in Plaza/Castle/Forja/Terrazas/Faro;
- bell and machinery as functional ambience;
- modest civic activity where already allowed by canon;
- preserve material identity and the accepted Plaza composition.

## Canonical shots
`final-return-plaza`, `arc1-final-pedestal` plus restored comparisons from earlier regions.

## Rule
Never apply a global "victory glow" or unrelated particles. Every final-state difference must trace to a restored service/system or an approved narrative beat.

## Avoid
New finale architecture, magical bloom, recoloring all copper, invented epilogue dialogue.
