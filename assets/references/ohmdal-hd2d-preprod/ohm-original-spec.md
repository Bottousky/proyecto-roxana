# Ohm provisional — especificación original

Ohm es un autómata consciente e instrumento de medida, no una mascota ni un solucionador.

- Silueta: base baja estable, carcasa trapezoidal, visor central, dos brazos sensores y emisor.
- Altura: 1,03 m; frente semántico: `+Z`; origen: centro de la base en el suelo.
- Partes nombradas: `sensor_mount`, `arm_left`, `arm_right`, `hatch_top`, `emitter_front`.
- Estados: reposo, locomoción, sensor desplegado, medida válida, medida bloqueada e incertidumbre.
- Cada estado cambia forma o ritmo y expone una etiqueta textual; el color nunca es el único canal.
- Derechos: diseño original de Proyecto Roxana para ASSET-001. No deriva de un personaje, robot o
  composición de terceros y no usó generación paga.
